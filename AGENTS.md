# Shared class project instructions

Multiple students develop this application in separate Codex chats connected to the same shared GitHub repository. Follow these rules for every task:

1. Before making changes, retrieve the latest version of the repository. Inspect local changes, fetch from GitHub, and safely incorporate the latest changes from the shared branch before starting work.
2. Preserve all existing application functionality.
3. Do not overwrite or discard another student's work. Preserve existing local changes and commits.
4. After completing a task, test the changes and commit them with a descriptive commit message.
5. Push completed changes to the shared GitHub repository.
6. Immediately before pushing, fetch and check whether other students have pushed new changes. If so, incorporate those changes safely and rerun relevant tests before pushing. If a push is rejected because the remote has advanced, repeat this check and integration process.
7. If conflicting changes cannot be safely combined, stop and explain the conflict rather than overwriting anyone's work.
8. Never force-push to the shared repository.
